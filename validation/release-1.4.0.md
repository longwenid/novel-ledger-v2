# novel-ledger-v2 v1.4.0

发布日期：2026-10-02。交付形式：本地版本发布包，未推送远程仓库。

## 本次变化

- 简单返修只生成段落补丁；输入也仅带问题段落及邻段，减少整章重复。
- 版本哈希、原文锚和字符位置共同校验，错误或重叠修改整笔拒收。
- 需要时可分段查询候选基稿或扩大上下文；扩大范围不重置返修次数。
- 历史修订可交补丁，无需改动的后章可复用原稿；所有候选仍完整核验事实与阅读效果。

此前的分层世界设计、场景布局/地图、人物小传与逐人对白意图、资源与认知账本、伏笔、事务恢复和完本审查均保留。

## 验证与发布结论

91 项工程测试通过；补丁独立前向检查 53 项通过，另验证切片边界、快照损坏与中断恢复。两卷完本后从首章修订、重新完本的独立设计检查通过。未发现当前覆盖范围内必须补齐的发布阻断，先发布使用，不继续加入未经需求验证的设计。

[完整验收报告](report.md)区分工程、真实短篇流程、文学评价与未验证范围。打包副本的测试结果与 SHA-256 清单随版本 ZIP 放在 releases 目录。

## 使用与兼容

解压后让宿主读取 [SKILL.md](../SKILL.md)，或把整个 novel-ledger-v2 文件夹放入宿主支持的技能目录。需要文件读写与 Python 3.9+，不依赖额外包。小说项目保存在独立目录。

已有 v2 项目无需迁移，既有规划模式保持不变；旧的待处理整章返修任务仍可继续。新版驱动需按任务协议支持可选 patches、reuse_original 与 expand_context；新书模板继续默认启用分层设计和人物档案。原版 novel-ledger 的数据库与命令不在兼容范围。

参阅 [局部修订用法](../references/repairs.md)。发布包不包含本地测试数据库和任务缓存，包含测试、正文样本、评审记录及重放脚本。

## 已知边界

本次只实测当前 macOS/Python 环境，未接通其他模型厂商；尚未完成百万至三百万字实写验收。工具不自动证明自然语言语义、人物对白或文学质量。字符/JSON 体积变化不是实际 token 或费用统计。聊天关闭后的持续运行需要宿主调度或已配置的通用驱动。
