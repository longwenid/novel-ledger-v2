# novel-ledger-v2 v1.4.1

发布日期：2026-10-02。本地 Git 提交、版本标签 v1.4.1 和 ZIP 发布包。

## 本次更新

开书时按各卷剧情职责分配参考篇幅，所有卷的 word_budget 合计须在作者确认的全书字数区间内。新书模板已包含预算字段。

规划及整体复核材料、进度查询显示各卷基准、已验收汉字数、偏差与建议剩余量。结束较早的卷释放参考空间，后续分配按未结束卷的剩余基准比例重算，整数分配保持总量一致。建议不改作者约定或自动改写剧情，接受或调整建议须通过正常规划任务留痕。

单卷参考预算不作为交稿门槛；不要求为了额度补写。全书字数区间、主线终局、人物弧与兑现验收保持不变。候选修订按自身有效正文重新统计，正式分支保持独立。

## 验证

100 项工程测试通过，其中新增 9 项篇幅预算测试。新书 CLI 实际走通初始化、预算查询和全书设计工作包；格式、编译及文档链接检查通过。发布包解压后再次运行完整测试，并核对文件 SHA-256；结果随包保存。

本次没有新增文学质量试验或外部模型实测。[验收报告](report.md)保留完整覆盖和边界。

## 使用与兼容

解压后读取 [SKILL.md](../SKILL.md)，或将整个 novel-ledger-v2 文件夹放入宿主支持的技能目录。运行需要文件读写及 Python 3.9+，仅依赖标准库。小说项目保存在独立目录。

已有项目未配置卷预算时继续运行并显示 not_configured，不补造预算。新章保存工具计算的汉字数，旧章缺少该字段时从原文计算，无需数据库迁移。运行中的既有任务保持原输入，后续新规划任务才带新增视图。使用方式见[开书与篇幅分配](../references/creation.md)。
