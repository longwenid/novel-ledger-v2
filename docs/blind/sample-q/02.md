# 第二章 船钱

阿荻的船拴在第三根桥桩上。许砚下来时，她正用铜勺刮船底的泥，没等他开口，便说不赊。

“不是借船。我想问下仓。”

“问路不要钱。问去年的事要。”

许砚掏出十二枚铜钱，挑了三枚给她。阿荻收下三枚，许砚还剩九枚。

她没把勺子放下，只让他把票压在膝上，别叫河风卷走。看到那个缺角的手印，她刮泥的动作慢了一点。

“你师傅没走大码头。”

“油不是在大码头领？”

“大船卸那里。你师傅那日是从下仓回来的，坐我的船。两只缸，我记得，因为其中一只漏，我拿自己的旧衣裳塞了半路。”

许砚问她肯不肯去仓里再说一次。

阿荻将泥倒进河里。船板上留着一个比碗口稍大的黑印。

“我说一次，你听。仓里的人也听。他们以后不许我的船靠岸，你给我饭吃？”

九枚钱在许砚掌心里，硌得比刚才十二枚还紧。他原先想把票交给一个认识水路的人，这事就有了帮手。现在票仍在自己腿上。

“那道刻痕，你认不认得？”

阿荻看了票背，说不像船记。她抬勺指了指下游桥洞：“下仓的水尺上也这么刻。仓吏量水的时候，刀尖往左收。”

许砚站起身，船晃了一下。阿荻用勺柄抵住岸石，没有扶他。

“今天涨水，别从桥洞底下钻。”

他上岸后回头，她已经重新刮起泥来。那三枚钱买到的消息不多，却都是她肯负责的话。
